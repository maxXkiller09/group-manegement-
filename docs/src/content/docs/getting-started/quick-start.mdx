Get **NexGuard** running in your Telegram group in just a few steps.

<Steps>
  <Step title="Add NexGuard">
    <Badge variant="accent">Step 1</Badge>
    <Tabs>
      <Tab title="Add to existing group">
        1. Open [@NexGuardd_Bot](https://t.me/NexGuardd_Bot) on Telegram
        2. Tap **Start**
        3. Choose **Add to Group**, or use this link: [Add NexGuard to a Group][add-to-group]
        4. Select your group and confirm
      </Tab>
      <Tab title="Create a new group">
        1. Create a Telegram group
        2. Add **@NexGuardd_Bot** from the member-selection screen
        3. Complete group creation
        4. You can also add NexGuard later using the group link above
      </Tab>
    </Tabs>
  </Step>
  <Step title="Grant required admin permissions">
    <Badge variant="accent">Step 2</Badge>
    :::caution[Admin permissions are required]
    NexGuard needs relevant Telegram admin permissions to perform moderation actions. Without them, actions such as deleting messages or restricting members may fail.
    :::
    1. Open your group settings
    2. Go to **Administrators**
    3. Select **NexGuard**
    4. Enable only the permissions your group needs, such as:
       - Delete messages
       - Ban users
       - Invite users via link
       - Pin messages
       - Manage video chats (optional)
  </Step>
  <Step title="Configure your group">
    <Badge variant="accent">Step 3</Badge>
    **Set group rules**
    ```
    /setrules Your group rules here.
    Be respectful and follow the guidelines.
    ```
    **Set a welcome message**
    ```
    /setwelcome Welcome {mention}! Please read our /rules before chatting.
    ```
    **Enable CAPTCHA (recommended)**
    ```
    /captcha on
    /captchamode math
    ```
    :::tip[Pro tip]
    Use `{mention}` to mention new members. Other supported placeholders may include `{chatname}` and `{count}`.
    :::
  </Step>
  <Step title="Explore commands">
    <Badge variant="accent">Step 4</Badge>
    Send `/help` in your group to see the available commands.
    Popular commands:
    - `/adminlist` — See group administrators
    - `/rules` — Display group rules
    - `/notes` — List saved notes
    - `/filters` — List active filters
    - `/locks` — Review lock settings
  </Step>
</Steps>
