# NexGuard

**Smart Protection. Better Communities.**

NexGuard is a Telegram group-management bot built with Go and the [gotgbot](https://github.com/PaulSonOfLars/gotgbot) library. It helps community owners and moderators protect, organize, and understand their groups with a practical set of moderation, automation, and management tools.

## What NexGuard helps you do

<CardGroup cols={2}>
  <Card title="Protect your community" icon="shield-check">
    Use bans, mutes, warnings, antiflood controls, blacklists, anti-raid tools, and CAPTCHA verification to reduce spam and disruptive activity.
  </Card>
  <Card title="Keep groups organized" icon="messages-square">
    Manage rules, notes, filters, pinned content, welcome messages, and member approvals.
  </Card>
  <Card title="Automate routine work" icon="workflow">
    Configure greetings, join-request approvals, scheduled moderation features, and group-specific settings.
  </Card>
  <Card title="Manage with clarity" icon="layout-dashboard">
    Use the Telegram Mini App dashboard and management commands to review activity and configure supported features.
  </Card>
</CardGroup>

## Built for dependable operation

- **Go-powered:** concurrent processing for responsive bot operations.
- **PostgreSQL:** persistent data storage with migrations and connection pooling.
- **Flexible deployment:** Docker-based self-hosting and supported cloud deployment options.
- **Multi-language:** English, Spanish, French, Hindi, Russian, Portuguese, and Indonesian locales.
